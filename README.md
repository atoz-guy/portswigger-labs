# PortSwigger Web Security Academy Labs

My write-ups for [PortSwigger Web Security Academy](https://portswigger.net/web-security) labs, completed with Burp Suite Community Edition.

Each write-up follows the same investigation method:

1. **Understand**: the vulnerability and the security boundary involved
2. **Observe**: the normal request and response
3. **Hypothesize**: what might be exploitable and why
4. **Test and Record Evidence**: each test with its actual result
5. **Conclude and Reflect**: root cause, risk, remediation and lessons learned
